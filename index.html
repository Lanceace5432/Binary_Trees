BINARY SEARCH TREE EDUCATIONAL GUIDE

What is a Binary Search Tree (BST) in C?

In C, a Binary Search Tree is constructed using a self-referential structure and memory pointers:

struct Node {
  int data;
  struct Node *left;
  struct Node *right;
};
  • The left pointer points to subtrees with data less than the current node.
  • The right pointer points to subtrees with data greater than the current node.
  • Subtree pointers are set to NULL when no children exist.

C Node Deletion Memory Cases

  1. Case 1 (Leaf Node): Target has NULL children. Sever pointer and free() node memory.
  2. Case 2 (Single Child): Target has one valid pointer. Replace node with child pointer and free target.
  3. Case 3 (Two Children): Locate In-Order Successor (smallest node in right subtree), copy data, then recursively delete successor node.
